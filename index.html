Cadangkan Data (Backup)

Semua data (kelas, siswa, presensi setiap tanggal) tersimpan di memori peramban HP/laptop ini. Unduh cadangannya secara rutin agar data tidak hilang, lalu simpan filenya ke Google Drive (unggah manual seperti unggah foto/dokumen biasa).

File backup berisi seluruh data kelas, siswa, dan presensi per tanggal. Cara paling mudah mengunggah ke Google Drive: buka Google Drive di HP/laptop → tombol "+ Baru" → "Upload file" → pilih file backup yang baru diunduh.

Unggah Otomatis ke Google Drive (Opsional/Lanjutan)

Fitur ini menghubungkan aplikasi langsung ke akun Google Drive Bapak/Ibu supaya backup bisa diunggah dengan satu klik, tanpa unduh-lalu-upload manual. Karena aplikasi ini berjalan mandiri (bukan lewat server Anthropic/Google resmi), fitur ini butuh "Google Client ID" milik sendiri yang dibuat lewat Google Cloud Console, dan aplikasi harus diakses lewat alamat web (http/https, mis. GitHub Pages/Netlify/hosting sekolah) — bukan dibuka langsung dari file di komputer.

Cara membuat Google Client ID (sekali saja)
  1. Buka console.cloud.google.com, buat proyek baru (mis. "Presensi SDN Tanjung 03").
  2. Menu "APIs & Services" → "Library" → aktifkan Google Drive API.
  3. Menu "APIs & Services" → "OAuth consent screen" → pilih External → isi nama aplikasi & email, simpan (status Testing sudah cukup, tambahkan email Bapak/Ibu sebagai Test user).
  4. Menu "Credentials" → "Create Credentials" → "OAuth client ID" → tipe Web application.
  5. Pada "Authorized JavaScript origins", isi alamat web tempat aplikasi ini dihost (mis. https://namasekolah.github.io).
  6. Salin "Client ID" yang muncul, tempel di kolom di bawah, lalu klik Simpan.
